## Stack context

- **Language:** Python 3.11+ (deterministic engine in `core/` + FastAPI backend in `webapp/backend/`);
  JS/JSX frontend (React 19 + Vite). **No TypeScript** (no `tsconfig`, plain JSX).
- **Numerical core:** pandas / numpy / scipy — the Wyckoff/VCP/LPS detector engine. The crown jewel;
  correctness bugs (lookahead, NaN, float-eq, off-by-one, determinism) live here.
- **Backend:** FastAPI + Pydantic + uvicorn; SQLAlchemy over **SQLite** (WAL, `busy_timeout=30000`)
  + **parquet** market-data cache (pyarrow); APScheduler for scans.
- **Market data:** yfinance (pinned `==1.2.1`) + **read-only** IBKR (`ib_async`) for open-trade enrichment.
- **Frontend:** React 19 + Vite, `lightweight-charts` + `recharts`; "Instrument Panel" design system
  (`PRODUCT.md` + `DESIGN.md`).
- **HARD SAFETY (carry into every run):** never place/modify/cancel trades; IBKR is read-only
  snapshots; never set `IBKR_LIVE_CONFIRMED` / `IBKR_AUTO_CONNECT`; **do NOT boot the backend**
  (`uvicorn` / `start_dashboard`) — *importing* `main` for a check is fine. Read `docs/strategy_v2.md`
  before any `core/structure` | `core/scoring` change.
