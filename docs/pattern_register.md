**The kill-by discipline is the flag ledger's:** by its date a row is advanced, killed, or re-dated
with a written reason — never silently carried.

**Intake rule:** a description enters when it carries (a) the operator's verbatim words, (b) the
catalog event it reads (or the new entry it proposes — `strategy_alpha.md`'s "a new signal declares
its event"), and (c) at least one named specimen (ticker + date). A description without a specimen
is a note — ask for the chart. Specimens are drawn in the calibration workbench into the ONE marks
DB under a population label (EC-9/EC-13) — never a new hand-rolled corpus file (the docs-root JSON
corpora are grandfathered history, not precedent).
