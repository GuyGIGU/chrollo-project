# Pattern Register — the front door for operator-described patterns

**Append rows; advance states; never delete.** One row per price-action pattern the operator has
described, per program a ruling opened, or per parked body of work that needs an owner. This file
holds STATE; [`decisions.md`](decisions.md) holds JUDGMENT — a row advancing to RULED cites its
decisions.md row, never restates it. Born from the 2026-08-22 "One System" council
(operator rule: no more parallel versions; every described pattern enters THE engine as a lane).
Full design: `.council/review-output/2026-08-22-2250/friedman.md` §Part B.

**States:** DESCRIBED → SPECIMENED → MEASURED → BUILT-DARK → RULED (LIVE / DEAD / SUPERSEDED).
**The kill-by discipline is the flag ledger's:** by its date a row is advanced, killed, or re-dated
with a written reason — never silently carried.

**Intake rule:** a description enters when it carries (a) the operator's verbatim words, (b) the
catalog event it reads (or the new entry it proposes — `strategy_alpha.md`'s "a new signal declares
its event"), and (c) at least one named specimen (ticker + date). A description without a specimen
is a note — ask for the chart. Specimens are drawn in the calibration workbench into the ONE marks
DB under a population label (EC-9/EC-13) — never a new hand-rolled corpus file (the docs-root JSON
corpora are grandfathered history, not precedent).

**Citation rule (2026-09-01):** a row cites code by SYMBOL — file plus function, method, constant or
`::test_name` — **never by line number**. Line citations rot when some *other* edit inserts above
them, so the change that breaks one never touches the file that carries it, and
`tools.audits.pointer_audit --check` cannot see it: it resolves paths, not line numbers. Measured on this
file's own program — the consolidation-method changeset's review rounds rotted five line citations
inside their own review (rows 12/13/15 here, plus two in [`flag_ledger.md`](flag_ledger.md)); row
12's was left pointing at unrelated comment prose while the code it names had moved ~200 lines down
the same file, and every gate stayed green through all five. A sixth, in
[`consolidation_method_2026-09.md`](consolidation_method_2026-09.md), was off by one line from the
day it was written. All six were converted to symbol citations at the round-four seam.

**Renumbering (2026-09-24):** rows 18 and 19 were numbered 11 and 12 on main (opened 2026-09-07)
until the consolidation-method branch merged onto the domain layout. That branch had already used
