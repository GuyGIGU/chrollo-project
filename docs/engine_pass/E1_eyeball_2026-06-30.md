## Track A — L2 event reader (measure-only)

**Calibrated `measure_resistance_events`** so SOS stops over-firing in active/extended boxes — two box-relative bounds:
- **Near-R bound** (`SOS_NEAR_R_MAX_BOX = 1.5`): a wave-top far above R (e.g. a pkPos 2.0–2.4 reach) is post-breakout **`markup`**, not an SOS creek-jump.
- **Real-consolidation hold** (`SOS_HOLD_MAX_RANGE_BOX = 0.55`): "held" now requires a genuine mini-consolidation (a tight band in the printed post-top window), not merely "no drop to the low-zone". Right-edge-honest (a hold that isn't fully printed stays `in_progress`), shakeout-tolerant.

**Added the remaining event bricks** (each independent, AREA-based, never gated on another): `test` (touch of S that holds — the one genuinely-new detector), plus a unified `read_box_events` assembler that reuses `find_spring` (spring), `detect_lps`/`find_lps` (LPS, Phase-D-gated purely on bar position), and `measure_resistance_events` (SOS/markup/upthrust/range/rejection). ## Track B — candle-spread readability grade (flag-gated, default OFF)

A self-referential bar-texture grade multiplies `box_tightness` behind `CANDLE_SPREAD_AWARE` (sibling of the ADR flip). Built from the existing measure-only `bar_compression` (spread/box, spread/ATR, tight-bar %) — each already normalized by the base's OWN box/ATR, so it is **never** an absolute bar-width threshold. Missing texture → neutral 1.0. Grade ∈ `[CANDLE_GRADE_FLOOR=0.55, 1.0]` — a GRADE, never a veto. Flag-off is byte-identical (proven).
