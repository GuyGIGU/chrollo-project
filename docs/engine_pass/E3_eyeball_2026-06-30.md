## The term (grades-not-vetoes)
`_puzzle_quality(narrative)` = one `[0,1]` composite (completeness and chronology are correlated, so one term,
not two):
```
composite = 0.70 * (completeness/4)  +  0.30 * {intact:1.0, partial:0.5, absent:0.0}
s_puzzle  = clamp(composite * SCORE_PUZZLE_QUALITY(=8), 8)      # added to total ONLY when the flag is on
```
- **Bonus-only**: `s_puzzle ∈ [0, 8]` — it can only *raise* a score, never gate/reject/touch firing
  (recall-safe by construction; `calculate_tier` is untouched, a higher score can only improve a tier).
- **Read on the engine's own box**: `assemble_box_narrative(df, structure.box, atr_for_zone)` re-runs the
  detectors on the *exact* `EquilibriumBox` the engine fired on → reproduces the fired spring/LPS bit-for-bit
  (object-identity test pins it). Parent equilibrium frame (in `lps_in_inner` cases the spine LPS is the
  parent-frame read — intentional).
