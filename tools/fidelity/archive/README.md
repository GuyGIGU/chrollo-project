# tools/fidelity/archive

Spent / superseded fidelity artifacts kept for the record — not read by any harness.

The live grading harness (`tools/fidelity_harness.py`) reads `tools/fidelity/labels.csv`
(regenerated on every `--render`). Files here are point-in-time hand-filled snapshots the
operator produced during an eyeball session, preserved for their notes but no longer consulted.

- `labels_filled_2026-06-07.csv` — hand-filled grading sheet from a 2026-06-07 eyeball
  (duplicate of the labels template; the harness never read `labels_filled.csv`). Archived
  2026-07-04 in the dead-code sweep.
