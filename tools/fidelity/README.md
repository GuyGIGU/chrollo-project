# tools/fidelity/ has moved

The chart-evidence sheets that lived here moved to
[`research/fidelity/`](../../research/fidelity/) on 2026-09-24, when `tools/`
was sorted into category folders. Every subfolder kept its name and its bytes,
so an old citation `tools/fidelity/<name>/<file>` now reads
`research/fidelity/<name>/<file>`.

This stub stays because sealed records still name their evidence under the old
`tools/fidelity/` prefix (the trend-end marks corpus in `docs/` is one), and a
sealed file is never edited to follow a move.
